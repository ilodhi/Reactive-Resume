# Legacy: Windows offline launcher (abandoned)

Adam previously wanted a 100% offline Windows desktop flow (`setup.cmd` / `setup.ps1` / `launch-resume.ps1` / `run-app.vbs`). That path was brittle (PowerShell parse / elevation issues) and is **no longer the supported way to run this project**.

**Current path:** deploy Reactive Resume as a Vercel web app — see the repository root [README](../../README.md).

These scripts are kept only for historical reference. Do not treat them as maintained.
